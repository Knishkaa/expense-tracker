# 💰 Python Expense Tracker

A simple command-line expense tracker built to practice Python logic and Git version control.

## 🚀 Features
* **Add Expenses:** Log spending amounts alongside categories.
* **View Expenses:** See your full list of saved expenses anytime.
* **Interactive Menu:** Run continuously in the terminal using a simple menu interface.

## 🛠️ Concepts Learned
* Dictionaries and Lists in Python
* Interactive `while` loops and `break` statements
* Functions and data return values
* Git version control and GitHub publishing
